# AC-12 known ILC warnings (PRD NFR-7, issue #27).
#
# tasks/aot-smoke/scan-il-warnings.sh fails a native-AOT publish log on ANY IL2xxx/IL3xxx line that is
# not matched here. Third-party warnings are where hidden reflection in an unannotated dependency
# shows up (NetCid's JcsCanonicalizer.Canonicalize(JsonNode) appeared in exactly this log), so they are
# not informational: each one is either listed here, with the reason it is unreachable, or a failure.
#
# Format: one entry per line, matched as a PREFIX of the normalized warning ("ILxxxx: <origin member>:
# <message>"), so an entry names the code and the member whose body raises the warning. Lines starting
# with '#' and blank lines are ignored.
#   <prefix>           an allowed warning
#   require <prefix>   a canary: allowed, and at least one warning must match it, or the scan fails
#
# What an entry cannot catch: ILC attributes a warning to the member whose body makes the call, so a
# new caller of a listed member produces no new line, and a different message at a listed member also
# matches. An entry is therefore only as good as its reason; the runtime legs of ac-12 prove only the
# paths tasks/aot-smoke exercises.

# The canary (IlCanary.cs): proves the ILCompiler's trim and AOT analysis ran and reached this log. A
# publish with the analysis suppressed logs no IL warnings and would otherwise pass.

require IL3050: DataProofsDotnet.Tools.AotSmoke.IlCanary.Run(): Using member 'DataProofsDotnet.Tools.AotSmoke.IlCanary.Annotated()'
