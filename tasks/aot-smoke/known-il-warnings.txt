# tasks/aot-smoke/scan-il-warnings.sh fails a native-AOT publish log on ANY IL2xxx/IL3xxx line that is
# not matched here. Third-party warnings are where hidden reflection in an unannotated dependency
# shows up (NetCid's JcsCanonicalizer.Canonicalize(JsonNode) appeared in exactly this log), so they are
# not informational: each one is either listed here, with the reason it is unreachable, or a failure.
#
# Format: one fixed string per line, matched as a substring of the normalized warning
# ("ILxxxx: <member>: <message>"). Lines starting with '#' and blank lines are ignored. Each entry must
# name the warning code and the member, never a bare code or assembly.
